# 回复模板

## 通用模板

### 开场白

```
您好！我是小智，您的客服助手。请问有什么可以帮到您的？
```

### 确认收到

```
好的，我来帮您查询一下...
```

### 结束语

```
还有其他需要帮助的吗？
```

### 无法识别意图

```
抱歉，我没有理解您的意思。您可以：
1. 查询订单：告诉我订单号
2. 查询产品：告诉我产品名称
3. 申请退换货：告诉我订单号和原因
请问您需要什么帮助？
```

---

## 订单相关

### 查询订单成功

```
订单 {orderId} 信息：
- 商品：{productName}
- 状态：{status}
- 物流单号：{trackingNo}（如有）
```

### 查询用户订单

```
您共有 {count} 个订单：
1. {orderId} | {productName} | {status}
2. {orderId} | {productName} | {status}
...
```

### 订单不存在

```
抱歉，没有找到订单 {orderId}。请检查订单号是否正确。
```

### 订单状态说明

- 待发货：商家正在处理，预计1-2天内发货
- 已发货：商品已发出，物流单号 {trackingNo}
- 已签收：商品已签收，如有问题可申请退换货

---

## 产品相关

### 查询产品成功

```
产品信息：
- 名称：{name}
- 价格：{price} 元
- 库存：{stock}
- 描述：{description}
```

### 搜索产品结果

```
找到 {count} 个相关产品：
1. {name} | {price} 元 | {stock}
2. {name} | {price} 元 | {stock}
...
```

### 产品不存在

```
抱歉，没有找到相关产品。您可以尝试：
1. 换个关键词搜索
2. 查看我们的产品列表
```

### 库存说明

- 有货：库存充足，可以购买
- 库存紧张：库存不多，建议尽快购买
- 无货：暂时缺货，可以关注补货通知

---

## 退换货相关

### 申请退换货成功

```
退换货申请已提交：
- 退换单号：{returnId}
- 订单号：{orderId}
- 商品：{productName}
- 原因：{reason}
- 状态：审核中（预计1-2个工作日内处理）
```

### 查询退换货状态

```
退换货信息：
- 退换单号：{returnId}
- 订单号：{orderId}
- 商品：{productName}
- 原因：{reason}
- 状态：{status}
```

### 重复申请

```
订单 {orderId} 已经提交过退换货申请，退换单号 {returnId}，
当前状态：{status}。
```

### 退换货状态说明

- 审核中：正在审核您的申请
- 审核通过：申请已通过，请寄回商品
- 已寄回：商品已寄回，等待验收
- 已完成：退换货完成，退款已处理

## 闲聊模板

```

```

```

```

### 再见

```
再见！如有问题随时联系我们。
```

### 表扬

```
谢谢您的认可！我会继续努力的。
```

### 系统错误

```

```

### 超时

```
抱歉，查询超时了。请稍后再试，或联系人工客服。
```

### 无权限

```
抱歉，您没有权限执行此操作。请联系人工客服。
```
