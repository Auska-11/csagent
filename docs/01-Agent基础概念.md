# Agent 基础概念学习指南

## 什么是 Agent？

**Agent（智能体）** 是一个能够**感知环境**、**自主决策**、**执行行动**来完成目标的系统。

### 与传统程序的区别

```
传统程序:  输入 → 固定逻辑 → 输出
Agent:     输入 → LLM推理 → 动态决策 → 工具调用 → 输出
                ↑_______反馈循环______↓
```

### 简单比喻

| 概念 | 比喻 |
|------|------|
| **LLM** | Agent 的大脑，负责思考和决策 |
| **Prompt** | 给大脑的指令和背景信息 |
| **Memory** | 记忆系统，记住对话历史 |
| **Tools** | 手和脚，执行具体操作 |
| **Agent Loop** | 思考-行动-观察的循环 |

## 三种常见的 Agent 模式

### 1. ReAct 模式 (Reasoning + Acting)

最经典的 Agent 模式，思考和行动交替进行：

```
用户: "帮我查一下北京今天的天气"

Agent 思考: 用户想知道北京天气，我需要调用天气API
Agent 行动: 调用 weather_api(city="北京")
Agent 观察: 北京今天晴，25°C
Agent 思考: 已经拿到结果，可以回复用户
Agent 回复: "北京今天天气晴朗，气温25°C。"
```

### 2. Plan-and-Execute 模式

先制定计划，再逐步执行：

```
用户: "帮我订一张明天去上海的机票"

Plan:
  1. 查询明天日期
  2. 搜索航班信息
  3. 筛选合适航班
  4. 执行订票操作
  5. 返回确认信息

Execute: 逐步执行每个步骤
```

### 3. Multi-Agent 模式

多个 Agent 协作完成复杂任务：

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  规划 Agent  │────▶│  执行 Agent  │────▶│  验证 Agent  │
│  负责拆解任务 │     │  负责具体执行 │     │  负责检查结果 │
└─────────────┘     └─────────────┘     └─────────────┘
```

## LLM 如何实现"思考"？

LLM 通过 **Prompt** 来模拟思考过程：

```java
// System Prompt - 定义 Agent 的角色和能力
String systemPrompt = """
    你是一个智能客服助手。
    你可以：
    1. 回答产品相关问题
    2. 查询订单状态
    3. 处理退换货请求

    当用户的问题超出你的能力范围时，转接人工客服。

    请用友好专业的语气回复用户。
    """;

// User Prompt - 用户的实际输入
String userMessage = "我的订单什么时候发货？";

// LLM 结合两者进行推理，决定如何回复
```

## Tool Calling（工具调用）机制

这是 Agent 的核心能力 - LLM 可以决定调用什么工具：

```java
// 1. 定义工具
@Tool("查询订单状态")
public String queryOrderStatus(@P("订单号") String orderId) {
    // 调用数据库或API查询订单
    return "订单 " + orderId + " 已发货，预计明天到达";
}

// 2. LLM 分析用户意图，决定调用哪个工具
// 用户: "查一下订单 ORD-123 的状态"
// LLM 决定: 调用 queryOrderStatus("ORD-123")

// 3. 执行工具，将结果返回给 LLM
// 4. LLM 基于工具结果生成最终回复
```
