# Smart CS Agent｜闲鱼卖家智能客服系统

**项目时间：** ［自行填写］

**技术栈：** Java 17、Spring Boot、MyBatis、MySQL、Spring Security、LangChain4j、Qdrant、Python、SQLite、Docker。

**项目描述：** 面向闲鱼个人卖家开发智能客服系统，支持商品咨询、多轮授权议价、知识问答和人工接管；通过 Python 侧车桥接平台消息与 Java 后端，结合工作流与大模型处理买家咨询，完成闲鱼真机消息收发验证。

- **业务编排：** 基于 Runtime、Workflow、Action Handler 与 Capability Gateway 分层实现多轮业务流程，保存跨轮报价与任务状态；确认时重新校验价格、库存和卖家授权，商品售出后停止推进，超出授权转卖家处理。
- **消息可靠性：** 采用 SQLite 持久化收件箱与固定并发任务，实现批量消息接收和同会话顺序处理；Java 侧结合消息标识、数据库唯一约束与结果回放处理重复请求，对执行或发送结果未知的消息停止自动重试。
- **权限隔离：** 基于 Spring Security/JWT 实现身份验证、角色鉴权和租户校验，结合 Workflow 与 Capability 白名单限制业务入口；按租户、用户与会话复合键隔离状态，防止不同身份读取或覆盖同名会话。
- **知识检索：** 将当前商品事实与型号知识分离，按渠道、品类和型号过滤资料；故障排查支持关键词与可选 Qdrant 向量混合召回，采用 RRF 融合、规则重排与相关性判断，向量通道失败时降级为关键词检索。
- **人工协作：** 支持商品草稿审核发布、版本冲突校验和会话接管，接管期间暂停自动回复并同步卖家消息；对接核实工单与结果回调，按商品和会话校验核实结果，处理结论撤回。
