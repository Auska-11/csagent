## 二、Skill 设计（重点）

### Skill 实现方式

**遵循 Anthropic Agent Skills 开放标准**：
- 每个 Skill 是一个目录，包含 SKILL.md 文件
- SKILL.md 使用 YAML frontmatter + Markdown 指令
- 启动时只加载 name + description（~100 tokens/skill）
- Agent 调用 `load_skill` 工具时，加载完整 SKILL.md body

### Skill 文件结构

```
app/agent/skills/definitions/
├── process-return/
│   └── SKILL.md          # 退货退款处理技能
├── track-order/
│   └── SKILL.md          # 订单物流跟踪技能
└── product-recommend/
    └── SKILL.md          # 商品推荐技能
```

### SKILL.md 格式

```markdown
---
name: process-return
description: 当用户要退货、退款、换货时使用...
---

## 退货退款处理流程

### 第一步：确认订单信息
- 如果用户提供了订单号，调用 `query_order` 查询订单详情
- 如果用户没有提供订单号，调用 `list_user_orders` 列出用户所有订单

### 第二步：判断订单状态
...
```

### Skill 加载策略

**渐进式披露（Progressive Disclosure）**：

1. **启动时**：只加载 name + description（~100 tokens/skill）
   ```python
   def get_catalog(self) -> list[dict]:
       return [
           {"name": s.name, "description": s.description}
           for s in self._skills.values()
       ]
   ```

2. **注入 System Prompt**：告诉 Agent 有哪些技能可用
   ```python
   def build_catalog_prompt(self) -> str:
       lines = [
           "## 可用技能（Skills）",
           "以下是你可以使用的专业技能...",
       ]
       for skill in self._skills.values():
           lines.append(f"- **{skill.name}**：{skill.description}")
       return "\n".join(lines)
   ```

3. **按需加载**：Agent 调用 `load_skill` 工具时才加载完整内容
   ```python
   def load_skill(self, skill_name: str) -> dict:
       skill = self._skills.get(skill_name)
       body = skill.load_body()
       return {
           "success": True,
           "skill_name": skill.name,
           "instructions": body,
       }
   ```

**好处**：
- 减少 token 消耗（不相关的 Skill 不加载）
- Agent 可以主动选择使用哪个 Skill
- 易于扩展新 Skill

## 三、Memory 设计

### 三级记忆架构

```python
class MemoryManager:
    def __init__(self, client, model, user_id, memory_dir, memory_enabled, max_ltm_facts):
        self.stm = ShortTermMemory()      # 短期记忆
        self.ltm = LongTermMemory(...)     # 长期记忆
```

### 短期记忆（ShortTermMemory）

**作用**：会话内事实提取

**实现**：
- 每轮对话后更新
- 使用 LLM 提取关键事实
- 存储在会话内

### 长期记忆（LongTermMemory）

**作用**：跨会话持久化

**实现**：
- 按 user_id 分文件存储（JSON）
- 会话结束时巩固关键事实
- 最多保留 50 条事实

### 记忆使用

```python
def build_memory_prompt_sections(self) -> list[dict]:
    """生成所有记忆相关的 system prompt 消息列表。"""
    sections = []
    ltm_section = self.ltm.build_prompt_section()
    if ltm_section:
        sections.append({"role": "system", "content": ltm_section})
    stm_section = self.stm.build_prompt_section()
    if stm_section:
        sections.append({"role": "system", "content": stm_section})
    return sections
```

## 五、评测体系

### 双层评测

**过程指标**（代码规则）：
- tool_accuracy：工具调用准确率
- tool_efficiency：工具调用效率
- token_cost：Token 消耗
- route_match：路由匹配度

**结果指标**（代码规则 + LLM Judge）：
- intent_match：意图匹配度
- keyword_coverage：关键词覆盖率
- answer_quality：回答质量（LLM Judge）
- faithfulness：忠实度（是否幻觉）

### 评测流程

```python
class Evaluator:
    def run_case(self, case: EvalCase) -> EvalResult:
        # 1. 沙箱运行
        trace = self.sandbox.run(case)
        
        # 2. 过程指标
        res.tool_accuracy = metrics.tool_accuracy(case.expected_tools, called)
        res.tool_efficiency = metrics.tool_efficiency(case.min_tool_calls, trace.num_tool_calls)
        
        # 3. 结果指标
        res.intent_match = metrics.intent_match(case.expected_intent, actual_intent)
        res.keyword_coverage = metrics.keyword_coverage(case.expected_keywords, reply)
        
        # 4. LLM Judge
        if self.use_judge:
            res.answer_quality = metrics.answer_quality_score(self.client, self.model, ...)
```
