# 智能客服 Agent 开发计划

## 项目目标

开发一个能写进简历的智能客服 Agent，重点体现技术深度。

---

## 核心功能清单

| 功能 | 描述 | 技术要点 |
|------|------|----------|
| 意图识别 | 理解用户想干嘛 | Prompt Engineering、LLM 分类 |
| 工具调用 | 执行实际操作 | @Tool、MCP 协议 |
| 多轮对话记忆 | 记住上下文 | ChatMemory、摘要压缩 |
| RAG 知识库 | 检索产品文档 | Embedding、向量检索、Reranker |

---

## 开发阶段

### 阶段一：基础对话（第1周）

目标：LLM 能作为客服角色对话

- [x] 项目初始化
- [ ] System Prompt 设计（客服角色）
- [ ] 带角色的对话接口
- [ ] 基础多轮对话（内存记忆）

**验收标准：** 能连续对话 5 轮，Agent 记住上下文

---

### 阶段二：意图识别 + 工具调用（第2周）

目标：Agent 能理解意图并调用工具

- [ ] 定义意图类型（查订单/退货/问产品/闲聊/其他）
- [ ] 实现工具类（OrderTools）
- [ ] Agent 自动选择工具并调用
- [ ] 工具调用失败处理（重试/降级/兜底）

**验收标准：** 用户说"查一下订单ORD-001"，Agent 自动调用查询工具并返回结果

---

### 阶段三：多轮对话记忆优化（第3周）

目标：长对话不丢失上下文

- [ ] 对话历史窗口管理
- [ ] 长对话摘要压缩
- [ ] 关键信息提取（订单号、用户意图）
- [ ] 记忆持久化（Redis/数据库）

**验收标准：** 20 轮对话后仍能记住之前的订单号

---

### 阶段四：RAG 知识库（第4周）

目标：Agent 能检索产品文档回答问题

- [ ] 文档加载与分块
- [ ] Embedding 向量化
- [ ] 向量存储与检索
- [ ] 检索结果注入 Prompt
- [ ] 检索质量优化（Query Rewriting、Reranker）

**验收标准：** 问"耳机续航多久"，Agent 从知识库检索并回答

---

### 阶段五：评测与优化（第5周）

目标：量化 Agent 质量

- [ ] 构建测试用例集（50+ 条）
- [ ] 自动化评测脚本
- [ ] 指标：准确率、响应时间、工具调用成功率
- [ ] Bad Case 分析与优化

**验收标准：** 能输出评测报告，准确率 > 80%

## 面试时怎么讲这个项目

> "我做了一个智能客服 Agent，核心亮点是：
> 1. 端到端的意图识别，通过 Prompt Engineering 实现零样本分类
> 2. 工具调用机制，支持订单查询、退换货等业务操作
> 3. 多轮对话记忆，通过摘要压缩解决长对话上下文丢失问题
> 4. RAG 知识库，接入产品文档提升回答准确性
> 5. 自动化评测体系，量化 Agent 质量并持续优化"
