# 智能客服 Agent 开发计划 v2.0

## 项目概述

项目名称：Smart CS Agent（智能客服 Agent）
技术栈：Java 17 + Spring Boot 3.3 + LangChain4j
项目目标：开发一个可写进简历、面试可深入讲解的 Agent 项目

---

## 设计理念

参考三个优秀开源项目的设计思想：

1. 分层解耦：Agent 核心、Skill 策略、工具能力、知识库各自独立
2. 渐进式开发：每完成一个阶段都能独立运行和讲解
3. 面试导向：每个模块对应一个可讲的技术亮点

---

## 整体架构

四层架构设计：

- Layer 1: Agent 核心（Runtime）- 会话管理、工具调用循环、记忆管理
- Layer 2: Skill 策略包 - 意图识别、对话流程、回复模板
- Layer 3: MCP Tools（业务能力）- 订单、产品、退换货等工具
- Layer 4: Knowledge（知识库）- 商品信息、FAQ、政策文档

---

## 开发阶段

### Phase 1：基础对话（已完成）

目标：LLM 能作为客服角色进行多轮对话

完成内容：
- [x] System Prompt 设定客服角色
- [x] 多轮对话记忆（滑动窗口）
- [x] 基础 API 接口

技术亮点：Prompt Engineering、ChatMemory

面试话术：我使用 System Prompt 定义客服角色，结合 MessageWindowChatMemory 实现多轮对话记忆，保留最近 20 条消息避免 token 超限。

---

### Phase 2：工具调用（进行中）

目标：Agent 能识别意图并调用工具执行操作

待完成内容：
- [x] 数据模型（User, Product, Order, ReturnRecord）
- [x] 数据仓库（Repository 层，模拟数据库）
- [ ] 工具类（UserTools, OrderTools, ProductTools, ReturnTools）
- [ ] 将工具注册到 Agent，实现自动调用

技术亮点：@Tool 注解、@P 注解、LLM 自动选择工具

面试话术：我设计了分层的工具架构，Repository 层封装数据访问，Tools 层定义业务能力。使用 @Tool 注解让 LLM 自动识别用户意图并选择合适的工具，工具内部实现可随时替换。

---

### Phase 3：RAG 知识库

目标：Agent 能检索知识库回答产品和政策问题

待完成内容：
- [ ] Markdown 知识文档（产品信息、FAQ、退换货政策）
- [ ] 文档加载与分块
- [ ] Embedding 向量化
- [ ] 向量存储与检索
- [ ] 查询改写（Query Rewriting）
- [ ] 检索结果注入 Prompt

技术亮点：RAG 检索增强生成、Query Rewriting 提升召回率

---

### Phase 4：记忆系统优化

目标：长对话不丢失上下文，支持跨会话记忆

待完成内容：
- [ ] 三级记忆架构（工作记忆、短期记忆、长期记忆）
- [ ] 对话摘要压缩（LLM 自动总结历史对话）
- [ ] 关键信息提取（订单号、用户偏好）
- [ ] 长期记忆持久化

技术亮点：三级记忆架构、LLM 自动摘要压缩、跨会话用户画像

---

### Phase 5：意图识别增强

目标：更准确地理解用户意图

待完成内容：
- [ ] 意图分类器（订单查询、退换货、产品咨询、闲聊）
- [ ] 关键词匹配 + LLM 分类双路识别
- [ ] 置信度评估与兜底策略

技术亮点：双路融合意图识别、置信度阈值与降级

---

### Phase 6：多 Agent 路由（可选）

目标：不同意图分配给专门的 Agent 处理

待完成内容：
- [ ] 意图路由器（Router）
- [ ] 售前 Agent（产品咨询、推荐）
- [ ] 售后 Agent（订单查询、退换货）
- [ ] 降级策略

---

### Phase 7：评测体系

目标：量化 Agent 质量，驱动持续优化

待完成内容：
- [ ] 测试用例集（50+ 条典型场景）
- [ ] 自动化评测脚本
- [ ] LLM-as-Judge 四维度评分
- [ ] 评测报告生成

## 面试一分钟版本

我做了一个智能客服 Agent，基于 LangChain4j 实现。核心亮点是：通过 @Tool 注解实现工具调用，Agent 能自动识别用户意图并调用订单查询、退换货等业务工具；使用三级记忆系统管理多轮对话上下文；接入 RAG 知识库回答产品问题；最后用 LLM-as-Judge 构建了自动化评测体系。
