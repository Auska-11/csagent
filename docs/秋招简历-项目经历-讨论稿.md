## 项目功能与特色（2026-10-07 核对）

项目定位：主打闲鱼个人卖家的智能客服 Agent，完成闲鱼真实消息收发验证，支持当前商品咨询、受卖家授权约束的议价、卖家核实和人工接管。订单查询、退货申请等通用商城能力作为已有工程积累保留，简历主线围绕闲鱼接待与卖家协作展开。

| 功能 | 具体行为 | 适用范围 |
| --- | --- | --- |
| 平台消息接待 | Python 侧车收取闲鱼 WebSocket 消息，注册买家身份后调用 Java Agent，并将回复发回闲鱼；按买家和商品维护会话 | 闲鱼渠道 |
| 商品咨询与议价 | 查询商品描述、价格与库存；按卖家授权规则报价，维护跨轮报价，确认时重新检查库存、价格及授权 | 闲鱼渠道；通用端支持商品搜索和推荐 |
| 商品使用与故障接待 | 按渠道、当前品类和型号筛选资料，证据不足时澄清或请卖家核实；型号能力与当前商品实况分别处理 | 闲鱼已补接待指南，厂商型号手册仍需完善；Qdrant 为可选混合检索 |
| 商品审核与授权配置 | 平台描述只建草稿，卖家核对成色、配件和授权后发布；保存及发布校验版本，发布资料即时生效 | 闲鱼卖家工作台，本次完成本地验证 |
| 人工接管与卖家核实 | 转人工后暂停自动回复，同步卖家人工消息，确认后恢复；与 SLA 平台联调核实工单及结果回调，恢复后可引用持久化的有效结果 | 闲鱼接管及 SLA 联调 |
| 多轮业务办理 | 缺少订单号、退货原因时追问，提交退货申请前要求确认，支持查询业务进度 | 通用客服端；闲鱼默认排除订单、退货与保修流程 |
| 管理与质量监控 | Trace 展示路由、检索、能力调用与耗时；反馈审核后沉淀为评测候选样本，支持回归评测 | 管理工作台 |

新增商品审核和消息接入加固已完成本地实现，细节见 [主线改造记录](闲鱼主线改造-2026-10-07.md)。

建议突出四个特色：

1. **真实渠道接入**：有闲鱼真机消息收发证据，平台协议由侧车承接，业务决策集中在 Java 后端。
2. **可控业务执行**：Workflow 保存任务状态，关键报价、授权校验和提交确认由代码控制。例如商品售出后，买家再确认历史报价时会告知售出，报价不会继续生效。
3. **人机协作闭环**：遇到未核实商品信息可请求卖家核实，暂停机器人；核实结果经工单平台回调持久化，恢复后按有效结果回答，撤回后停止引用旧结论。
4. **可观察、可回归的后端工程**：会话隔离、幂等与结果未知处理、检索降级、Trace 和场景评测共同支撑可靠性。

接入证据：部署手册记录了 2026-09-06 买家小号真机消息经 Java 回复回闲鱼且会话写入 MySQL；工作计划还记录了 2026-09-05 商品问题回复引用真实商品价格。最新运维记录为 2026-09-10 本地侧车经 SSH 隧道连接云端 Agent，BRIDGE 注册在线，切换后真机复验待执行。本次只核对仓库记录，没有检查当前在线状态。

## 第一版推荐稿

**Smart CS Agent｜闲鱼卖家智能客服 Agent**

**技术栈：** Java 17、Spring Boot、Spring Security、MyBatis、MySQL、LangChain4j、Python、Docker；项目另有 Qdrant 混合检索实现。

**项目描述：** 面向闲鱼个人卖家的二手商品接待，构建支持商品咨询、多轮授权议价、卖家核实和人工接管的客服 Agent；通过 Python 侧车完成闲鱼真实消息收发验证。

- **渠道接入与可靠性：** 通过 Python 侧车桥接闲鱼 WebSocket 与 Java Agent，按买家和商品映射会话；采用持久化收件箱、有界并发和 Java 幂等回执处理批量与重复消息，发送结果未知时停止自动重发。
- **业务编排与授权：** 基于 Runtime、Workflow、Action Handler、Capability Gateway 分层执行商品咨询和多轮议价；卖家规则约束底价、让价与包邮，确认时复核库存、价格及授权，未核实事项暂停机器人转卖家处理。
- **商品事实与知识：** 将当前商品事实与型号知识分离，资料通过草稿、版本校验和审核发布更新，平台价格库存独立同步；检索按渠道、品类与型号过滤，支持关键词/Qdrant 混合召回、融合重排及向量降级。
- **身份与质量保障：** 基于 Spring Security 校验 JWT，结合租户、角色及能力白名单限制业务入口；提供卖家审核和人工接管工作台，通过 Trace、场景评测与故障回归检查越权、已售保护、接管打断和重复执行。

以上为本地主线改造后的候选文案，不添加未验证的线上业务量、准确率或性能收益。新增消息可靠性和卖家页面尚未部署到真实渠道。

## 央国企软件开发 / 信息化岗位候选稿

本版按 Java 软件开发岗位组织内容，优先展示业务流程、权限控制与消息可靠性。项目场景保留闲鱼个人卖家接待，项目性质、起止时间与个人职责按实际经历填写。投递 AI 应用开发岗位时，可将智能辅助一条前移，并继续使用“闲鱼卖家智能客服 Agent”名称。

**Smart CS Agent｜智能客服与卖家协同系统（闲鱼场景）**

**技术栈：** Java 17、Spring Boot、Spring Security、MyBatis、MySQL、LangChain4j、Python、Docker。

**项目描述：** 面向闲鱼个人卖家的商品接待场景，开发支持商品咨询、授权议价、资料审核发布和人工接管的智能客服系统，完成闲鱼真实消息收发验证。

- **业务流程：** 基于工作流与会话状态管理实现多轮议价和人工接管；报价确认时复核价格、库存及卖家授权，接管后暂停自动回复；商品资料通过草稿、版本校验和审核发布更新。
- **权限控制：** 基于 Spring Security 和 JWT 校验身份，结合角色、租户及能力白名单限制接口访问；按租户、用户和会话隔离状态，保护卖家资料维护与会话控制入口。
- **消息可靠性：** 通过 Python 侧车桥接闲鱼 WebSocket 与 Java 服务，采用持久化收件箱、有界并发和同会话顺序处理；结合数据库唯一约束与结果回放处理重复请求，发送结果未知时停止自动重发。
- **智能辅助与验证：** 使用 LangChain4j 接入大模型，将商品事实与知识检索分离，按渠道、品类和型号过滤检索资料；记录工作流与能力调用 Trace，通过异常场景回归验证越权、重复消息及人工接管等流程。

文案调整建议来自岗位匹配判断，不代表所有央国企都有统一偏好。中国移动招聘官网目前同时列有 IT 开发与系统运营、信息技术研发与运营、Agent 开发等岗位，应继续根据具体岗位说明调整条目顺序：[中国移动招聘官网](https://job.10086.cn/)。

## 可以一起调整的重点

- **更偏 Java 后端：** 优先渠道可靠性、业务状态与授权。可将最后一条展开为 JWT、回执数据库唯一约束、CAS 和有界任务；工单 Outbox 的结果未知作为面试追问素材。
- **更偏 AI 应用：** 将商品事实与知识放在第二条，重点解释模型负责措辞、代码控制报价和权限、证据不足转卖家的职责。
- **篇幅控制：** 需要三条时将身份保障并入渠道接入与业务授权；项目起止时间按实际经历补充。最终条目、篇幅和措辞一起确定。
