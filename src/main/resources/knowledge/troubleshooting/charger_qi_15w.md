# 无线充电器 Qi 15W 兼容与安全 FAQ

关键词：无线充电器, Qi, 15W, 快充, 功率, 发热

## 快充协议与功率兼容

关键词：快充协议, Qi协议, 15W, 功率兼容, 充电慢, PD, QC

充电器输出端支持最高 15W Qi 无线充电，实际功率由手机、充电板和输入适配器三方协商决定。要达到 15W，需要手机支持对应 Qi 功率档位，并使用支持 USB PD 或 QC、额定功率不低于 20W 的输入适配器；不兼容时会自动降低到 5W、7.5W 或 10W，不会把 15W 强行输入手机。厚于 3 毫米、带金属片或磁吸环位置不正确的保护壳可能导致充电慢或无法充电。

## 异常发热

关键词：异常发热, 很烫, 烫手, 焦味, 冒烟, 停止使用

无线充电能量转换会产生轻微温升，设备温热但可正常触摸通常不代表故障。若充电器烫到无法持续触摸、反复停止充电、出现焦味、冒烟、外壳变形，或手机提示温度过高，应立即移开手机并断开充电器电源。检查充电区域是否夹有硬币、钥匙或金属片，待完全冷却后不要继续试充，直接联系人工客服。禁止覆盖充电器散热面或自行拆机。
