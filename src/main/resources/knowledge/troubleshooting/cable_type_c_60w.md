# Type-C 60W 数据线兼容与故障 FAQ

关键词：Type-C, USB-C, 数据线, 60W, 充电, 数据传输

## 接口与功率兼容

关键词：接口兼容, Type-C, USB-C, 60W, PD快充, 功率

本线两端为 USB-C 接口，支持最高 60W USB PD 充电；实际功率还取决于充电器和设备是否支持相同的 PD 档位。它不能直接插入 USB-A、Lightning 或 Micro-USB 接口，使用转接头后也不保证快充。60W 是线材可承载上限，不代表所有设备都会以 60W 充电。

## 无法充电或充电不稳定

关键词：无法充电, 充不进电, 接触不良, 断断续续, 接口松动

先确认两端插头完全插入，并检查设备接口内是否有绒毛或异物；清洁前应断开电源，不要使用金属工具。分别更换一个已知正常的充电器和设备进行交叉测试。如果只有弯折线材或按压接头时才能充电，说明连接不可靠，应停止使用并联系人工客服，不要继续折弯或自行修补。

## 只能充电不能传输

关键词：只能充电不能传输, 不能传文件, 电脑不识别, 数据通道, USB 2.0

本线支持 USB 2.0 数据传输。连接电脑后，应在手机上解锁屏幕并把 USB 用途从“仅充电”切换为“文件传输”；部分设备默认只充电。换用电脑的另一个 USB-C 数据端口，并避免只供电的扩展坞端口。若同一设备使用其他数据线可以传文件，而本线在多台电脑上都只能充电，请联系人工客服检测线材的数据通道。
