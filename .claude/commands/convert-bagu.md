# 八股格式转换 Skill

## 任务
将用户提供的原始八股文资料，严格按照标准模版格式进行重写和整理。

## 标准模版格式

```markdown
模块X：{主题名称}
Q{N}：{问题}（{难度}）
● 核心关键词：{词1}、{词2}、{词3}
● 回答范式：
  a. {大要点}：
    ■ {子要点详细说明}
  b. {大要点}：
    ■ {子要点详细说明}
    ■ {子要点详细说明}
```

## 格式规范

### 1. 模块层级
- 每个模块以 `模块X：` 开头，X 为中文数字（一、二、三...）
- 模块名体现该组问题的核心主题
- 建议每个模块 3~6 个问题

### 2. 问题编号
- 全局连续编号：Q1、Q2、Q3... 不因模块变化而重置
- 问题末尾标注难度：（低）、（中）、（高）、（高频）
  - 低：基础概念，偶尔问到
  - 中：中频考点，需要掌握
  - 高：高频考点，必须熟练
  - 高频：面试几乎必问

### 3. 核心关键词
- 用 `● 核心关键词：` 标识
- 3~5 个关键词，用中文顿号 `、` 分隔
- 关键词应该是回答该问题时必须提到的核心概念/术语

### 4. 回答范式
- 用 `● 回答范式：` 标识
- 大要点用 a/b/c... 编号，后跟冒号
- 子要点用 ■ 标识，缩进 4 个空格
- 回答风格要求：
  - **口语化**：像在面试中直接说出来一样
  - **直击要点**：不绕弯子，先说结论再展开
  - **有层次**：先总后分，由浅入深
  - **可背诵**：适合面试前直接背诵
  - 每个子要点应是一句完整的话，而不是零散的词语

### 5. 内容质量要求
- 技术准确性：基于权威资料，不能有错误
- 完整性：覆盖问题的核心知识点，不遗漏关键内容
- 深度适中：够面试用，不需要过于深入源码
- 包含"面试陷阱"或"面试要点"作为加分项

## 转换流程

当用户提供原始资料时，按以下步骤操作：

1. **分析原始内容**：提取所有知识点、问题和答案
2. **重新分组**：按主题归类到不同模块
3. **提炼问题**：将内容转化为面试问答形式
4. **标注难度**：根据面试频率和重要性标注
5. **提取关键词**：每题提炼 3~5 个核心关键词
6. **重写回答范式**：按标准格式重写，确保口语化和层次感
7. **全局检查**：
   - 编号是否连续
   - 格式是否统一
   - 难度标注是否合理
   - 关键词是否准确
   - 回答范式是否可直接背诵

## 输出要求

- 输出为 Markdown 文件
- 文件名建议：`{语言/技术栈}/八股篇.md`
- 每个问题之间空一行
- 模块之间空两行
